# 📖 The Small Web Reader

> **PECathon 2026 — Problem Statement PS-003**  
> **Team:** PF-UTDAW7  
> **Core Principle:** Read the web without algorithms. Follow blogs directly, read full articles offline, and discover new writers through anonymous co-subscription recommendations.

---

## 🌟 Key Features
- **🪐 3D Spatial Perspective Tunnel:** Immersive literary landing page spotlighting independent blogs and longform essays.
- **☕ Warm Editorial Typography:** Distraction-free, warm-parchment aesthetic designed for slow reading.
- **🛡️ 100% Anonymous & Private:** Zero tracking, no accounts or persistent IDs required.
- **⚡ Client-Side First:** Feed parsing, article extraction (Mozilla Readability), and local caching (IndexedDB).
- **📶 Offline Support:** Download and read articles seamlessly even without internet access.

---

## 🛠️ Tech Stack
- **Framework:** Next.js 16 (App Router, TypeScript)
- **Styling:** Tailwind CSS + Lucide Icons + Framer Motion
- **Design System:** shadcn project structure & components
- **Client Cache:** IndexedDB / LocalStorage

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to experience the 3D scroll tunnel.
