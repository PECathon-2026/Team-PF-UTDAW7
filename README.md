# The Small Web Reader 🌐

**PECathon 2026 | Problem Statement PS-003**  
**Team ID:** PF-UTDAW7

The Small Web Reader is a privacy-focused platform that helps users discover and follow independent blogs without relying on algorithmic feeds or user tracking.

Users can subscribe to blogs through RSS/Atom feeds, read articles in a distraction-free environment, and discover new writers through anonymous co-subscription recommendations.

## ✨ Features

- **RSS/Atom Subscriptions:** Follow independent blogs directly.
- **Distraction-Free Reading:** Read full articles with clean typography.
- **Anonymous Discovery:** Discover blogs through co-subscription recommendations.
- **Offline-First:** Access cached articles and subscriptions.
- **Privacy-Focused:** No user accounts, tracking cookies, or persistent user identifiers.
- **OPML Support:** Import and export subscriptions.

## 🛠️ Tech Stack

- Next.js
- TypeScript
- Supabase
- Prisma
- RSS/Atom Parser
- Mozilla Readability
- DOMPurify

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/PECathon-2026/Team-PF-UTDAW7.git
cd Team-PF-UTDAW7
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
